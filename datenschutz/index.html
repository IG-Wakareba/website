Datenschutzhinweise

Diese Hinweise beziehen sich auf die statische Website der IG WaKaReBa.

Besuch der Website

Diese Website verwendet keine eigenen Analysewerkzeuge, Werbetracker, Kontaktformulare oder Cookies. Beim Aufruf einer Seite werden technisch notwendige Verbindungsdaten durch den Hosting-Anbieter verarbeitet. Die Website wird über GitHub Pages bereitgestellt. Informationen zur Datenverarbeitung durch GitHub finden Sie in der Datenschutzerklärung von GitHub.

Externe Links

Einige Seiten verlinken auf externe Angebote, zum Beispiel Dokumente von Google Drive oder Websites von Behörden. Beim Öffnen solcher Links gelten die Datenschutzbestimmungen des jeweiligen Anbieters. Diese Website lädt die verlinkten Inhalte nicht automatisch ein.

Kontakt und Auskunft

Bei Fragen zum Datenschutz erreichen Sie die IG WaKaReBa unter info@wakareba.ch.

Hinweis für die Betreiber*innen: Diese Seite ersetzt die frühere Jimdo-/Google-Analytics-Erklärung. Vor Veröffentlichung prüfen, ob GitHub Pages und alle externen Verlinkungen dem tatsächlichen Betrieb entsprechen.
